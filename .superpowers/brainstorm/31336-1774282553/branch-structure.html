Branch Structure & Assignment

How many branches exist and how does the owner see them?

A

Exactly 2 Branches

There are only 2 branches in the system (e.g., Jasaan Branch + one other). The branch owner sees both side by side. Fixed, not expandable.

B

Flexible Assignment

Multiple branches can exist. Each branch owner is assigned to specific branches (1, 2, or more). Admin manages which branches each owner can see.

C

Franchise Owner View

Multiple branches exist. The branch owner sees ALL branches — a high-level franchise overview with the ability to drill into each one.
