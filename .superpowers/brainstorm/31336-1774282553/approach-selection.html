Implementation Approach

How should we architect multi-branch support?

A

Branch-Scoped Database ⭐ Recommended

Add branches table + branch_id to existing tables (orders, products, inventory, users). All queries filter by branch. Existing data migrated to default "Jasaan Branch". Clean, scalable, single database.

✓ Clean architecture · ✓ Scalable · ✓ Cross-branch reports easy · ⚠ Requires schema migration
B

Separate Database Per Branch

Each branch gets its own database. Branch Owner connects to multiple DBs. Complete data isolation but complex maintenance and cross-branch reporting.

✓ Full isolation · ✗ Hard to maintain · ✗ Cross-branch reports complex
C

View/Filter Layer Only

Minimal changes — add branch tables, tag new records only. Old data stays untagged. Least invasive but inconsistent and limited.

✓ Least invasive · ✗ No historical context · ✗ Inconsistent filtering
