Who is the "Branch Owner"?

How should branch ownership map to your existing role system (Admin, Manager, Cashier)?

A

New Role: Branch Owner

A brand new role separate from Admin/Manager/Cashier. Each branch owner logs in and only sees their assigned branch(es) — sales, products, delivery data.

B

Admin = Owner

The existing Admin role acts as the branch owner. Admin can toggle between branches to view each one's sales data, products sold, and delivery info. Other roles stay the same.

C

Upgrade Manager Role

Managers become branch owners — each is assigned to a specific branch and sees only that branch's data. Admin still has full access to all branches.

Something Else
